    ☁️ 多设备数据同步（手机 / 电脑1 / 电脑2）

    本应用是纯本地存储（localStorage），三个设备默认各存各的。下面第一种「云端同步」能真正让三设备互通（数据存到你自己的私有 GitHub Gist）；其余是备用搬运方式。

    ☁️ 云端同步（GitHub Gist）— 推荐，三设备真正互通

    把数据存到你名下的私有 GitHub Gist，任何设备登录同一账号点一下就能同步，不用每晚手动导文件。
    ① 去 GitHub 生成一个 只勾 gist 权限 的 Token（点此打开，勾 "gist" 一项即可）；② 粘贴保存；③ 首次点「⬆️上传到云端」自动创建私有备份，之后「上传 / 同步」即可。

    ⚠️ 安全：Token 仅保存在本机浏览器，不会进入应用数据（即不会被同步出去）。数据存在你私有 Gist，仅持 Token 者可访问。用完可随时在 GitHub 撤销该 Token。

    📁 备用方式一：导出 / 导入数据文件

    导出成一个 .json 文件 → 用微信"文件"、邮件、U盘发到另一台设备 → 在那台设备上点"选择文件导入"。文件不像长串同步码会被截断，且在本地预览(127.0.0.1)里也能导出/导入。

    🔗 备用方式二：生成同步链接（仅限已部署的公网网址下）

    点下方按钮生成带数据的网址，发到另一台设备打开即自动导入。注意：只能在"已部署的公网网址"里生成才有效；在本地预览(127.0.0.1)生成的链接别的设备打不开。

    📤 备用方式三：同步码（手动复制粘贴，手机易截断）
    📥 导入同步码（覆盖当前数据）
    💡 三设备怎么用（云端同步）

    ① 任意设备都能记录，数据都进你同一个私有 Gist。
    ② 记完点「⬆️上传到云端」；换设备时点「⬇️从云端同步」即可拿到最新。
    ③ 云端以"最后一次上传"为准——为避免互相覆盖，建议只用一台主力机记录，其他设备先用「同步」拉最新再记。
